直连协议 SNI

SNI 安全提示：不要使用 Cloudflare / Akamai 等代理或 CDN 域名作为 SNI，否则端口被扫描后会沦为无限制流量转发端口。不确定就留空（内置默认值）。

② Argo 隧道协议与配置VMess / Trojan / Vless Argo 可多选

固定隧道请填写上方固定隧道域名与隧道 Token；自有 CF Tunnel 可在 fscarmen CF Json 生成网获取 JSON Token（仅选了 Argo 协议才需要）。粘贴多行 Token 会自动并成一行。

⚠️ 该端口为 Cloudflare 中配置隧道的 HTTP 对应的映射端口，比如 127.0.0.1:8001。

③ WS-CDN 回源可选，经 CDN 反代到 nginx，可与 Argo 并存，可多选

④ 全局配置

direct_host 仅对直连协议（hy2 / tuic / vless-reality / anytls / socks5）生效。Argo 与 CDN 回源（ws_cdn）协议各有自己的 CDN 域名，不受此项影响。

⑥ 安装 / 管理动作sb.sh 尾部参数

选择 del / delall / list 等管理动作时，将只生成不带环境变量的管理命令。

⑦ 节点订阅

⚠️ 开 Argo 时若 nginx_pt 与 Argo 回源端口（argo_pt，默认 8001）相同，会自动避开改成 8080（回源端口是 8080 时则改成 8001），两者相同装不上。

🔙 WS-CDN 回源时：CDN 回源端口 = 服务器 nginx_pt（默认 8080），请在 Cloudflare 后台把 origin rule 重定向该端口（或 origin rule 泛域名回源）。

📌 订阅地址 URL = https://域名/sub/UUID，域名自动按以下顺序取：有固定 Argo（隧道存活）就直接用固定 Argo → 否则用「共享回源域名 ws_cdn_sni」→ 否则用「专属回源域名 ws_cdn_vmess_sni / ws_cdn_vless_sni / ws_cdn_trojan_sni（取第一个非空）」→ 否则用「临时 Argo」→ 最后才是 http://IP:nginx_pt（明文）。

生成的 SSH 一键命令 sb.sh

提示：单行模式下整条命令只有一行，即使终端把换行吃掉也不会断（FinalShell 等推荐）；多行模式每行一个变量便于核对，但粘贴时若终端吞换行，行尾的 \ 会失效导致命令报错。

① 安装模式与基础参数

自定义 SECRET 后，无论重装多少次，分享链接保持一致（非法值将中止安装）。
